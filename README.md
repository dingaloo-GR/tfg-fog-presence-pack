## Quick Install (CurseForge App)

1. **[Click here to download TerraFirmaGreg-Modern-Fog-Presence-0.13.18.zip](https://github.com/dingaloo-GR/tfg-fog-presence-pack/releases/latest/download/TerraFirmaGreg-Modern-Fog-Presence-0.13.18.zip)**
2. Open the **CurseForge** desktop app and go to **Minecraft**.
3. Click **+ Create Custom Profile** (top right) -> click **"import a previously exported profile"** (or **Import**).
4. Select the downloaded TerraFirmaGreg-Modern-Fog-Presence-0.13.18.zip file.
5. Recommended RAM: In CurseForge **Settings -> Minecraft -> Java Settings**, allocate **6,144 MB – 8,192 MB (6–8 GB)** of RAM.
6. Launch the pack and join the server!
